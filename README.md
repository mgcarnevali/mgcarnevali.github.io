# mgcarnevali.github.io — Redesign preview

This is a preview of the proposed website redesign. It has **not** been deployed to GitHub.

## Review locally

Because stylesheet paths are absolute, run a local static web server from this folder:

```powershell
py -m http.server 8000
```

Open `http://localhost:8000/` and `http://localhost:8000/NvProfileSwitcher/`.

The product screenshots load from the official public NvProfileSwitcher repository on GitHub, so an internet connection is required to view them. The layout automatically follows your operating system's light/dark theme.

When approved, upload the *contents* of this folder (not the folder itself) to the root of `mgcarnevali.github.io`, replacing the old files.
